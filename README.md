# Rehab Treatment SQL Analysis

## 1. 프로젝트 소개

본 프로젝트는 근골격계 환자의 치료 기록과 통증 평가 데이터를 활용하여  
**치료 부위, 치료 유형, 치료 횟수 및 치료 빈도에 따른 통증 변화 패턴을 SQL로 분석한 프로젝트**입니다.

실제 환자 데이터는 사용하지 않았으며, 재활치료 환경을 가정하여 생성한  
**Synthetic Dataset(가상 데이터)** 을 활용하였습니다.

분석 기간은 **2026년 9월**이며, MySQL을 이용하여 데이터를 분석하였습니다.

---

## 2. 분석 목적

단순히 치료 횟수만 비교하는 것이 아니라 치료 기간과 주당 치료 빈도를 함께 고려하여 다음 내용을 확인하고자 하였습니다.

- 치료 부위 및 치료 유형별 환자 분포
- 환자별 치료 횟수와 치료 기간
- 주당 치료 빈도
- 첫 통증점수와 마지막 통증점수의 변화
- 치료 빈도에 따른 통증 변화
- 치료 부위 및 치료 유형에 따른 치료 패턴과 통증 변화

> 본 프로젝트는 SQL 분석 연습을 위한 가상 데이터 프로젝트이며, 특정 치료의 임상적 효과나 인과관계를 검증하는 연구가 아닙니다.

---

## 3. 데이터 구성

총 **48명의 가상 환자 데이터**를 사용하였습니다.

- 환자: 48명
- 치료 기록: 223건
- 통증 평가 기록: 144건

### PATIENT

환자의 기본 정보를 저장하는 테이블입니다.

| Column | Description |
|---|---|
| PATIENT_ID | 환자 ID |
| AGE | 나이 |
| SEX | 성별 |

### TREATMENT_RECORD

환자의 치료 기록을 저장하는 테이블입니다.

| Column | Description |
|---|---|
| TREATMENT_ID | 치료 기록 ID |
| PATIENT_ID | 환자 ID |
| TREATMENT_DATE | 치료일 |
| BODY_PART | 치료 부위 |
| TREATMENT_TYPE | 치료 유형 |

치료 부위:

- NECK
- SHOULDER
- LOW_BACK
- KNEE

치료 유형:

- MANUAL_THERAPY
- INJECTION
- HEAT_ELECTROTHERAPY

### PAIN_ASSESSMENT

환자의 통증 평가 기록을 저장하는 테이블입니다.

| Column | Description |
|---|---|
| ASSESSMENT_ID | 평가 ID |
| PATIENT_ID | 환자 ID |
| ASSESSMENT_DATE | 평가일 |
| PAIN_SCORE | 통증점수 |

## 4. 분석 질문

### Q1. 치료부위와 치료유형별로 몇 명의 환자가 치료를 받았는가?

`GROUP BY`와 `COUNT(DISTINCT)`를 이용하여  
치료 부위와 치료 유형별 환자 수를 확인하였습니다.

---

### Q2. 환자별 총 치료 횟수, 치료기간, 주당 치료빈도는 얼마인가?

환자별로 다음 값을 계산하였습니다.

- 총 치료 횟수
- 첫 치료일
- 마지막 치료일
- 치료 기간
- 주당 치료 빈도

주당 치료 빈도는 다음과 같이 계산하였습니다.

`치료 횟수 × 7 / 치료 기간`

---

### Q3. 환자별 첫 통증점수와 마지막 통증점수는 얼마나 변했는가?

`FIRST_VALUE()`와 `LAST_VALUE()` 윈도우 함수를 이용하여  
환자별 첫 통증점수와 마지막 통증점수를 계산하였습니다.

통증 개선폭은 다음과 같이 정의하였습니다.

`PAIN_IMPROVEMENT = FIRST_PAIN - LAST_PAIN`

따라서 값이 클수록 통증점수가 더 많이 감소한 것으로 해석하였습니다.

---

### Q4. 치료빈도에 따라 통증 변화는 어떻게 달랐는가?

환자를 주당 치료빈도에 따라 세 그룹으로 구분하였습니다.

- 주 1회 미만
- 주 1회 이상 ~ 2회 미만
- 주 2회 이상

분석 결과:

| 치료빈도 그룹 | 환자수 | 평균 주당 치료빈도 | 평균 통증 개선폭 |
|---|---:|---:|---:|
| 주 1회 미만 | 7 | 0.89 | 0.14 |
| 주 1~2회 미만 | 22 | 1.58 | 1.45 |
| 주 2회 이상 | 19 | 2.34 | 2.37 |

본 가상 데이터에서는 **치료빈도가 높은 그룹일수록 평균 통증 개선폭도 크게 나타나는 패턴**을 확인할 수 있었습니다.

---

### Q5. 치료부위와 치료유형에 따라 치료 횟수, 치료빈도, 통증 변화는 어떻게 달랐는가?

치료부위와 치료유형별로 다음 지표를 비교하였습니다.

- 환자 수
- 평균 치료 횟수
- 평균 주당 치료 빈도
- 평균 통증 개선폭

일부 결과 예시는 다음과 같습니다.

| 치료부위 | 치료유형 | 환자수 | 평균 치료횟수 | 평균 주당빈도 | 평균 통증 개선폭 |
|---|---|---:|---:|---:|---:|
| LOW_BACK | MANUAL_THERAPY | 7 | 4.86 | 1.86 | 2.71 |
| LOW_BACK | HEAT_ELECTROTHERAPY | 5 | 6.20 | 2.27 | 2.20 |
| NECK | HEAT_ELECTROTHERAPY | 4 | 5.00 | 2.26 | 3.25 |
| SHOULDER | MANUAL_THERAPY | 4 | 3.75 | 1.82 | 2.00 |

## 5. 주요 인사이트

본 가상 데이터에서는 다음과 같은 패턴을 확인하였습니다.

1. 치료 빈도가 증가할수록 평균 통증 개선폭도 증가하는 경향이 나타났습니다.
2. 같은 치료 유형이라도 치료 부위에 따라 평균 치료 횟수와 통증 변화가 다르게 나타났습니다.
3. 환자별 치료 횟수뿐만 아니라 치료 기간과 주당 치료빈도를 함께 고려하는 것이 치료 패턴을 이해하는 데 유용하였습니다.
4. SQL의 집계 함수와 윈도우 함수, CTE 및 JOIN을 활용하여 여러 테이블의 데이터를 결합하고 분석할 수 있었습니다.

## 9. 한계점

본 프로젝트는 SQL 학습 및 포트폴리오 제작을 목적으로 생성한 가상 데이터를 사용하였습니다.

따라서 분석 결과를 실제 환자의 치료 효과로 해석할 수 없으며,  
치료 선택 역시 무작위 배정이 아니므로 치료 유형 간의 인과관계를 판단할 수 없습니다.

또한 실제 임상환경에서는 환자의 진단, 질환 중증도, 치료 방법, 치료 강도, 동반질환 등 다양한 요인이 통증 변화에 영향을 줄 수 있습니다.
